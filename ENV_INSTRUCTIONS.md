# Настройка переменных окружения

## Обязательные переменные

- `BOT_TOKEN` — токен вашего Telegram-бота

## Рекомендуемые переменные

- `CHANNEL_ID` — чат, куда публикуются грузы и машины. По умолчанию группа «Грузоперевозки»: `-1001140181745`. Пробелы и переносы строки отбрасываются. `@tranzitpro1` не используется. В этой группе объявления уходят в тему форума `407642` (закрытое «Общее» даёт ошибку `TOPIC_CLOSED`).
- `ADMIN_ID` — ваш числовой Telegram ID (бесплатное размещение грузов + подтверждение оплат)
- `DATABASE_PATH` — путь к базе данных (по умолчанию `bot.db`)

## Размещение объявлений

Подписка на канал и приглашения **не требуются**. Кнопки «📦 Разместить груз» и «🚚 Разместить свободную машину» открываются сразу.

Бесплатное размещение грузов (без оплаты) — админ `ADMIN_ID` и список
`FREE_POST_USERNAMES` / `FREE_POST_USER_IDS`. По умолчанию в коде: `@Oleg34381`.

| Переменная | Назначение |
|---|---|
| `FREE_POST_USERNAMES` | @username через запятую — груз без оплаты (по умолчанию `Oleg34381`) |
| `FREE_POST_USER_IDS` | Числовые Telegram id через запятую — то же, надёжнее username |

## Оплата за размещение грузов

Логисты платят **за каждое** объявление о грузе. Водители (машины) — бесплатно.
Оплата **ручная**: перевод по реквизитам → «Я оплатил» → админ подтверждает → публикация.

| Переменная | Назначение |
|---|---|
| `ADMIN_ID` | Кто подтверждает оплаты и кто публикует грузы бесплатно |
| `AD_POST_PRICE` | Цена одного объявления, текст для пользователя (напр. `50 000 сум`) |
| `PAYMENT_DETAILS` | Реквизиты: карта, телефон, комментарий к платежу |
| `PAYMENT_ENABLED` | `1` (по умолчанию) или `0` — временно выключить оплату |

Команды админа: `/pending` — заявки на проверке; `/payinfo` — текущий тариф (всем).

## Контакты в объявлениях

Бот **всегда** показывает контакт того, кто разместил груз/машину:
1. телефон или @username из текста объявления;
2. иначе Telegram @username автора;
3. иначе имя из профиля Telegram.

`CONTACT_USERNAME` **не подставляется** в объявления (раньше из‑за этого
везде светился один и тот же контакт владельца).

## Рекомендуемые значения

```
BOT_TOKEN=...
CHANNEL_ID=-1001140181745
ADMIN_ID=123456789
FREE_POST_USERNAMES=Oleg34381
# FREE_POST_USER_IDS=123456789
AD_POST_PRICE=50 000 сум
PAYMENT_DETAILS=Карта: 8600...\nТел: +998...
DATABASE_PATH=bot.db
```

**Как настроить:**
1. Скопируйте `.env.example` → `.env`
2. Заполните значения в `.env`
3. Добавьте переменные в Railway (Variables)
4. **Никогда** не коммитьте `.env` в git
